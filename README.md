# Wanderly

Wanderly is a modern, responsive travel and tourism homepage designed for a fictional travel company. It helps visitors discover popular destinations, browse curated travel packages, understand the brand's benefits, and begin planning a trip through a simple call-to-action form. Built with HTML, CSS, and JavaScript, the website includes responsive navigation, smooth scrolling, interactive buttons, destination cards, and a clean travel-focused design that works across desktop, tablet, and mobile devices.
